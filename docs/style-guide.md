# Базовые стили: простые правила

Коротко. Никаких частных случаев на глаз — берём значение из шкалы. Если нужного размера нет в шкале — берём ближайшую ступень, а не новое число.

## Отступы (паддинги, гапы, маргины)

Шкала кратна 4px. Токены объявлены в `src/lib/styles/variables.scss` (доступны в любом компоненте автоматически, файл преферендится vite-конфигом):

| Токен | px | Где применять |
|-------|-----|----------------|
| `$sp-1` | 4 | иконка от текста, мелкие щели |
| `$sp-2` | 8 | дефолтный gap |
| `$sp-3` | 12 | паддинг карточки/секции на мобилке (аналог `p-3`) |
| `$sp-4` | 16 | паддинг карточки/секции на десктопе (аналог `lg:p-4`), gap крупных блоков |
| `$sp-6` | 24 | отступ между секциями |
| `$sp-8` | 32 | крупные разрывы |

Правила:

1. **Паддинг карточки/секции всегда `@include card-padding;`** — это `$sp-3` → `$sp-4` от 1024px. Не писать `padding: 14px` руками.
2. **gap по умолчанию `$sp-2` (8px)**. Между крупными блоками — `$sp-4`. Между секциями страницы — `$sp-6`.
3. Значения **между ступенями запрещены**: нет 5px, 7px, 10px, 13px, 14px, 18px. Ближайшая ступень.
4. Радиусы: 8px (мелочь), 12px (карточка), 999px (капсула/пилюля). Других не придумывать.

## Компоненты вместо копипасты

Если блок с отступами повторяется третий раз — выносить в компонент (кнопка, карточка, капсула) или в `controls.scss`, а не копировать стили. Новые общие кнопки — класс `.btn` из `controls.scss`.

## Что уже есть, не изобретать

- Цвета — только `$green` / `$green-light` / `$yellow` из variables, плюс нейтральные gray из существующих компонентов.
- Кнопки — `.btn.primary` / `.btn.secondary` / `.btn.secondary-with-border`.
- Тултип — `src/lib/components/Tooltip.svelte` (клик, не ховер).
- Маска телефона — `use:phoneMask` из `$lib/actions/phoneMask.ts`.
