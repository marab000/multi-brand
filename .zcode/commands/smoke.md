---
description: Функциональный smoke-тест сайта (страницы, АПИ, поиск)
---

Проведи функциональную проверку сайта. Дев-сервер должен быть поднят (порт 5199, strictPort); если не отвечает — запусти `npm run dev` в фоне и дождись готовности.

Порядок:

1. Запусти `npm run test:smoke` — он проверяет GET-доступность всех публичных страниц, ключевых АПИ (поиск, подсказки, слайды, настройки, фид) и страницу конкретного товара. Скрипт ничего не пишет в базу.
2. Каждый FAIL разбирай вручную: открой URL, посмотри ответ/ошибку в логах dev-сервера, найди причину в коде. Не чини молча — докладывай, что сломано и почему, и жди «го» (кроме мелких однозначных правок).
3. Дополни автоматический прогон интерактивными проверками, которые скрипт не покрывает (через браузер или curl):
   - поиск из шапки: ввод текста → появляются подсказки, переход на выдачу работает;
   - корзина: «В корзину» на карточке товара → счётчик, страница /cart показывает товар, −/+ меняют количество;
   - оформление: /checkout заполняется, заказ/заявка отправляется (на дев-базе это безопасно), редирект на /checkout/success;
   - заявка с /podbor отправляется (POST /api/podbor/request).
   Если пункт нельзя проверить без записи в прод-базу — остановись и спроси.
4. Итог: список «что проверено / что сломано / что починено», по каждому багу — файл и строка.

Аргументы после команды — доп. указания (например, конкретная страница или `--base=http://...` для проверки прода через туннель; прод тестировать GET-ами, записи — только с явного разрешения).
