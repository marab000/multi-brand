Переписать `docs/style-guide.md` железными правилами стилей (старый файл заменить целиком). Правила на основе разведки кода + твоих решений (брейкпоинты sm/md/lg/xl, tailwind для геометрии, карточки m-3 lg:m-4, радиусы 8/12/16/999).

Структура файла:

**0. Главный принцип.** Симметрия и следование UI/UX-правилам: одинаковые блоки — одинаковые отступы сверху/снизу и слева/справа; парные элементы — одинаковые размеры; ритм страницы строится на одной шкале. Если два зеркальных элемента выглядят по-разному — это баг, а не стиль. Перед коммитом смотри на блок целиком: равенство зазоров, выравнивание краёв, одинаковые высоты парных элементов.

1. **Цвета — только из палитры проекта.**
   - Бренд: `$green #0f3d1f`, `$green-light #3e6f4f`, `$yellow #e6a73c`, акцент-красный `#e31b23` (цены/акции), `$success/$error`.
   - Нейтральные: текст `#111827`, второстепенный `#374151`/`#475569`, приглушённый `#6b7280`/`#94a3b8`, границы `#e4e7ec`/`#eee`, фон `#fff`/`#fafafa`/`#f8fafc`.
   - Новые цвета «на глаз» не заводить: нужен цвет — берём из этого списка, нет подходящего — добавляем токен в variables.scss и используем везде через него. Нативные браузерные акценты перекрыты глобально (зелёная система фокуса).

2. **Размеры и отступы — только шкала 4px, mobile-first.**
   - Отступы пишем tailwind-классами: `p-3 lg:p-4`, `gap-2`, `mb-3 lg:mb-4`. Никаких голых `margin: 16px` в scoped SCSS, когда классом можно.
   - Если отступ в SCSS неизбежен — токены `$sp-1..8` (4/8/12/16/24/32/40/48), никаких сырых px.
   - Дефолт карточки/блока: `p-3 lg:p-4` (12 → 16, = `@include card-padding`).
   - Внутренние зазоры (gap): `gap-2` (8px) между связанными элементами, `gap-3 lg:gap-4` (12→16) между блоками.
   - Запрещённые значения: 5, 6, 7, 10, 13, 14, 18, 20px и прочий офф-скейл. Исключения: 1px границы, 2px мелкие детали, 999px.
   - Адаптив всегда mobile-first: мобильное значение, потом `lg:` / `@media (min-width: …)`. `max-width` медиа в новом коде запрещены.

3. **Брейкпоинты — только sm 640 / md 768 / lg 1024 / xl 1280.** Самодельные (1023, 639, 560, 520, 900, 1000) запрещены.

4. **Разделение tailwind / scoped SCSS.**
   - Tailwind: геометрия и раскладка (flex/grid/gap/padding/width/align).
   - Scoped SCSS: цвета, типографика, hover/focus, сложные компоненты. BEM (`&__`, `&--`) обязателен.

5. **Радиусы — только 8 / 12 / 16 / 999 / 50%.** Контролы 8, карточки 12, крупные секции 16, пилюли 999.

6. **Типографика.**
   - В SCSS — в rem: 0.75rem метки, 0.8125–0.875rem текст, 0.9375–1rem акценты; h1–p глобально из typography.scss.
   - Веса: 700 заголовки/акценты, 600 подзаголовки/кнопки, 400 текст. Приглушённый текст — класс `text-secondary`.

7. **Контролы.** Кнопки — `.btn .primary/.secondary`, инпуты — `.input`, чекбоксы — глобальные нативные/`.checkbox`. Дубли стилей кнопок в страницах запрещены; 3-е повторение паттерна → вынос в controls.scss.

8. **Переходы.** `transition: 0.15s ease` или `0.2s`, свойства background/border/box-shadow/color/transform. Никаких `transition: all`.

9. **Чек-лист перед коммитом:** шкала 4px? брейкпоинт из четырёх разрешённых? цвет из палитры? парные отступы симметричны? контрол из controls.scss, а не самописный?
